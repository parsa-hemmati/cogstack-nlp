# GDPR Compliance Checklist

**Application**: Clinical Care Tools
**Date**: 2025-11-22
**Status**: Production Readiness Phase 7
**Target Compliance**: 100% GDPR compliance for EU personal data

---

## Executive Summary

This checklist verifies compliance with the General Data Protection Regulation (GDPR) (EU 2016/679), which applies to any organization processing personal data of EU residents.

**Key Areas**:
- Lawful Basis for Processing
- Data Subject Rights
- Data Protection by Design
- Data Protection Impact Assessment (DPIA)
- International Data Transfers
- Third-Party Relationships
- Documentation & Audit

---

## 1. Lawful Basis for Processing (5 items)

### Legal Grounds
- [ ] Consent obtained and documented (if applicable)
- [ ] Consent is freely given, specific, informed, and unambiguous
- [ ] Consent can be withdrawn at any time
- [ ] Alternative legal basis identified if not consent-based
- [ ] Legal basis documented in privacy notice

**Legal Basis Used**: ☐ Consent ☐ Contract ☐ Legal Obligation ☐ Vital Interest ☐ Public Task ☐ Legitimate Interest

---

## 2. Data Subject Rights (12 items)

### Right to Access (Article 15)
- [ ] Procedure to provide copy of personal data implemented
- [ ] Response timeframe 30 days established
- [ ] Format for data access defined (electronic format provided)
- [ ] Mechanism to verify data subject identity in place

### Right to Rectification (Article 16)
- [ ] Procedure for correcting inaccurate data implemented
- [ ] Easy-to-use correction interface provided
- [ ] Data accuracy verification process in place
- [ ] Inaccurate data marked or corrected promptly

### Right to Erasure (Article 17)
- [ ] "Delete account" functionality implemented
- [ ] Data secure deletion procedure established
- [ ] Exceptions documented (legal obligations, etc.)
- [ ] Third parties notified of deletion request (where practical)

### Right to Restrict Processing (Article 18)
- [ ] Ability to request processing restriction implemented
- [ ] Flag system for restricted data in place
- [ ] Processing halted for flagged data
- [ ] Data subject notification procedures documented

### Right to Data Portability (Article 20)
- [ ] Data export functionality implemented
- [ ] Machine-readable format provided (JSON, CSV, etc.)
- [ ] Ability to transmit to another controller
- [ ] Direct transmission between controllers where possible

### Right to Object (Article 21)
- [ ] Easy mechanism for objecting to processing provided
- [ ] Marketing opt-out mechanism available
- [ ] Processing stopped upon objection
- [ ] Legitimate interest assessment documented

### Rights Related to Automated Processing (Article 22)
- [ ] No fully automated decisions with legal/significant effect
- [ ] If used, safeguards documented
- [ ] Human intervention procedures established
- [ ] Right to explanation provided

### Exercising Rights
- [ ] Procedure for rights requests documented
- [ ] No unreasonable delays in responding
- [ ] Response provided free of charge
- [ ] Requests tracked and documented

---

## 3. Data Protection by Design & Default (5 items)

### Privacy by Design
- [ ] Data minimization implemented (collect only necessary data)
- [ ] Purpose limitation enforced (use only for stated purpose)
- [ ] Storage limitation enforced (retention periods defined)
- [ ] Accuracy requirements documented
- [ ] Integrity and confidentiality controls in place

### Privacy by Default
- [ ] Highest privacy settings as default
- [ ] Opt-in for non-essential processing
- [ ] User control over personal data
- [ ] Regular review of default settings
- [ ] Privacy impact assessment conducted

---

## 4. Data Protection Impact Assessment (3 items)

### DPIA Completion
- [ ] DPIA conducted for high-risk processing
- [ ] DPIA process documented
- [ ] Regular updates to DPIA schedule

### DPIA Content
- [ ] Purpose of processing described
- [ ] Necessity and proportionality assessed
- [ ] Risk assessment completed
- [ ] Mitigation measures documented
- [ ] Consultation with supervisory authority (if high risk)

---

## 5. Data Privacy & Security (8 items)

### Technical Safeguards
- [ ] Encryption in transit (TLS 1.2+)
- [ ] Encryption at rest (AES-256)
- [ ] Secure authentication (strong passwords, MFA)
- [ ] Access controls (RBAC, least privilege)
- [ ] Data integrity controls (checksums, hashes)
- [ ] Audit logging of access and changes
- [ ] Regular security testing and vulnerability assessments
- [ ] Intrusion detection/prevention systems

### Organizational Safeguards
- [ ] Data protection officer (DPO) designated/assigned
- [ ] Data protection training for all staff
- [ ] Data processing contracts with vendors
- [ ] Incident response plan documented
- [ ] Data breach notification procedures in place
- [ ] Regular security risk assessments
- [ ] Policies and procedures documented
- [ ] Third-party processor audits conducted

---

## 6. Data Processing Agreements (4 items)

### Processor Contracts
- [ ] Written Data Processing Agreement (DPA) with all processors
- [ ] DPA includes all mandatory GDPR clauses
- [ ] Sub-processor authorization obtained
- [ ] Sub-processor notifications provided to data subjects

### Contract Requirements
- [ ] Processing instructions clear and documented
- [ ] Confidentiality obligations included
- [ ] Security measures specified
- [ ] Sub-processor clauses included
- [ ] Data subject rights acknowledgment
- [ ] Audit and inspection rights included
- [ ] Data deletion/return procedures specified
- [ ] Liability and indemnification clauses

---

## 7. International Data Transfers (5 items)

### Transfer Mechanisms
- [ ] Transfers only to adequate countries/regions
- [ ] Standard Contractual Clauses (SCCs) in place (if not adequate)
- [ ] Binding Corporate Rules (BCRs) if applicable
- [ ] Schrems II ruling assessed and addressed
- [ ] Supplementary safeguards implemented (if needed)

### Adequacy Assessment
- [ ] Recipient country data protection laws reviewed
- [ ] Transfer impact assessment completed
- [ ] Mechanism for safe transfer identified
- [ ] Documentation maintained

---

## 8. Transparency & Accountability (6 items)

### Privacy Notice
- [ ] Privacy policy available (accessible, clear language)
- [ ] Controller identity and contact information provided
- [ ] Purpose of processing clearly stated
- [ ] Legal basis for processing explained
- [ ] Data categories processed listed
- [ ] Recipients of data identified
- [ ] Retention period specified
- [ ] Rights available to data subjects explained
- [ ] Complaint procedure information provided
- [ ] Automated decision-making explained (if applicable)
- [ ] Notice available in multiple languages (if applicable)

### Records of Processing
- [ ] Records of Processing Activities (ROPA) maintained
- [ ] Processing activities documented
- [ ] Data inventory/mapping completed
- [ ] Joint controller relationships documented
- [ ] Updated regularly as processing changes

---

## 9. Data Breach Notification (4 items)

### Breach Response
- [ ] Breach discovery notification procedure documented
- [ ] Breach assessment process in place
- [ ] Notification to supervisory authority (within 72 hours)
- [ ] Notification to data subjects (if high risk)

### Documentation
- [ ] Breach log maintained
- [ ] Breach details documented
- [ ] Mitigation measures recorded
- [ ] Prevention measures for future breaches identified

---

## 10. Third-Party Relationships (3 items)

### Vendor Management
- [ ] Vendor assessment for GDPR compliance
- [ ] DPA in place with all vendors
- [ ] Regular vendor compliance audits
- [ ] Vendor data protection standards documented

### Subcontractors
- [ ] Subcontractor authorization required
- [ ] Subcontractor notified to data subjects
- [ ] Subcontractor DPA in place
- [ ] Same data protection obligations required

---

## 11. Data Subject Requests (3 items)

### Request Handling
- [ ] Documented procedure for handling rights requests
- [ ] Request tracking system in place
- [ ] 30-day response deadline met
- [ ] Extensions documented (if needed)

### Request Types
- [ ] Access requests processed
- [ ] Deletion requests processed
- [ ] Portability requests processed
- [ ] Restriction requests processed
- [ ] Objection requests processed

---

## 12. Special Categories of Data (2 items)

### Sensitive Data Handling
- [ ] Explicit consent obtained for special categories
- [ ] Health data processed with special safeguards
- [ ] Restricted access to sensitive data
- [ ] Enhanced security for sensitive data
- [ ] Limited retention period for sensitive data

### Age of Digital Consent
- [ ] Parental consent obtained for users under 16 (or local age)
- [ ] Age verification mechanism in place
- [ ] Consent process child-friendly

---

## 13. Cookies & Tracking (3 items)

### Cookie Management
- [ ] Cookie consent banner implemented
- [ ] Consent required before non-essential cookies
- [ ] Opt-in for tracking/analytics
- [ ] Cookie policy available
- [ ] Easy cookie withdrawal mechanism

### Analytics & Tracking
- [ ] Analytics tools GDPR-compliant
- [ ] Tracking tools configured to minimize data
- [ ] Privacy-friendly analytics tool chosen (if possible)
- [ ] User tracking consent documented

---

## 14. Organization & Governance (4 items)

### Data Protection Officer
- [ ] DPO designated (if applicable)
- [ ] DPO contact information published
- [ ] DPO has independence and resources
- [ ] DPO consulted on processing activities

### Accountability Framework
- [ ] Data protection policies established
- [ ] Staff training on GDPR requirements
- [ ] Compliance monitoring in place
- [ ] Documentation of compliance efforts
- [ ] Annual compliance review conducted
- [ ] Evidence of compliance maintained

---

## 15. Marketing & Communications (2 items)

### Marketing Compliance
- [ ] Opt-in consent for marketing email/SMS
- [ ] Unsubscribe mechanism easy to use
- [ ] Consent records maintained
- [ ] No pre-ticked consent boxes

### Profiling & Targeting
- [ ] Profiling practices disclosed
- [ ] Profiling subject to opt-in (if creating significant effect)
- [ ] Right to object to profiling easy to exercise
- [ ] Profiling purposes clearly stated
