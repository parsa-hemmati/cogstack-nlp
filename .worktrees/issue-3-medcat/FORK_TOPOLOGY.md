## Commands for Branch Management

### View detailed branch info
```bash
git branch -r | grep "myfork/"
git for-each-ref --format='%(refname:short) | %(authordate:relative) | %(subject)' refs/remotes/myfork/
```

### Delete merged branches
```bash
git push myfork --delete <branch-name>
```

### Sync with upstream
```bash
git fetch origin
git checkout main
git merge origin/main
git push myfork main
```

### Check which branches are merged
```bash
git branch -r --merged myfork/main | grep "myfork/"
git branch -r --no-merged myfork/main | grep "myfork/"
```
