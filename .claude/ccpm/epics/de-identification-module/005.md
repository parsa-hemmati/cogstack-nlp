# Task #005: Implement Audit Logging and Database Schema

## Description

Create HIPAA-compliant audit logging infrastructure and database schema for tracking all de-identification activities. Includes PostgreSQL tables for jobs and PHI entities, Elasticsearch indexes for audit trails, and comprehensive logging service.

## Technical Specifications

**Goal**: Complete audit trail infrastructure for HIPAA compliance

**Database Schema**:

### PostgreSQL Tables

**Table 1: deidentification_jobs**
```sql
CREATE TABLE deidentification_jobs (
    job_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id),
    status VARCHAR(20) NOT NULL,
    method VARCHAR(20) NOT NULL,
    total_notes INT NOT NULL,
    processed_notes INT DEFAULT 0,
    error_count INT DEFAULT 0,
    notify_email VARCHAR(255),
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP NOT NULL DEFAULT NOW(),
    completed_at TIMESTAMP,
    CONSTRAINT valid_status CHECK (status IN ('pending', 'processing', 'completed', 'failed', 'cancelled')),
    CONSTRAINT valid_method CHECK (method IN ('removal', 'replacement', 'generalization'))
);

CREATE INDEX idx_jobs_user_id ON deidentification_jobs(user_id);
CREATE INDEX idx_jobs_status ON deidentification_jobs(status);
CREATE INDEX idx_jobs_created_at ON deidentification_jobs(created_at);
```

**Table 2: phi_entities**
```sql
CREATE TABLE phi_entities (
    entity_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    job_id UUID NOT NULL REFERENCES deidentification_jobs(job_id),
    note_id VARCHAR(255) NOT NULL,
    entity_type VARCHAR(50) NOT NULL,
    start_offset INT NOT NULL,
    end_offset INT NOT NULL,
    confidence FLOAT NOT NULL,
    manually_reviewed BOOLEAN DEFAULT FALSE,
    action VARCHAR(20) NOT NULL,
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    CONSTRAINT valid_confidence CHECK (confidence >= 0 AND confidence <= 1),
    CONSTRAINT valid_action CHECK (action IN ('remove', 'replace', 'generalize'))
);

CREATE INDEX idx_phi_job_id ON phi_entities(job_id);
CREATE INDEX idx_phi_entity_type ON phi_entities(entity_type);
CREATE INDEX idx_phi_confidence ON phi_entities(confidence);
```

## Implementation Requirements

### 1. Audit Logging Service

**Service Design**:
```python
backend/app/services/audit_service.py
├── AuditService (class)
│   ├── log_deidentification(user_id, job_id, note_id, entities, method)
│   ├── log_job_created(user_id, job_id, total_notes)
│   ├── log_job_completed(job_id, processed_notes, error_count)
│   ├── log_job_cancelled(job_id, user_id, reason)
│   ├── log_access(user_id, action, resource_id, ip_address)
│   └── search_audit_logs(filters: Dict) → List[AuditEntry]
```

**Required Audit Events**:
1. Job created (user_id, total_notes, method)
2. Job started processing (job_id, timestamp)
3. Note de-identified (note_id, entities_removed, method)
4. Job completed (job_id, total_processed, errors)
5. Job cancelled (job_id, user_id, reason)
6. Access to de-identified notes (user_id, note_id, action)
7. Manual review (user_id, note_id, corrections)

### 5. HIPAA Compliance Requirements

**Must Log**:
- ✅ User ID (who accessed PHI)
- ✅ Timestamp (when accessed)
- ✅ Action (what was done: view, deidentify, download)
- ✅ Resource ID (which notes/jobs)
- ✅ IP address (from where)
- ✅ User agent (which application)
- ✅ Result (success/failure)

**Must NOT Log**:
- ❌ PHI content (patient names, MRNs, etc.)
- ❌ Original clinical text (only de-identified text)
- ❌ Sensitive entity text (only entity types)
