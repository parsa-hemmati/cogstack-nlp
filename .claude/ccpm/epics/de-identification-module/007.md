# Task #007: Create Manual Annotation Tool and Job Tracking

## Description

Implement manual annotation interface for human-in-the-loop review to catch missed PHI (8% safety net). Includes text selection tool, entity type picker, confidence adjustment, and job tracking dashboard. Annotations feed back into model training for continuous improvement.

**Text Selection Logic**:
```typescript
const handleTextSelection = () => {
  const selection = window.getSelection()
  if (!selection || selection.isCollapsed) return

  const selectedText = selection.toString()
  const range = selection.getRangeAt(0)

  // Calculate character offsets
  const startOffset = getCharacterOffset(textArea.value, range.startContainer, range.startOffset)
  const endOffset = getCharacterOffset(textArea.value, range.endContainer, range.endOffset)

  // Show annotation toolbar
  const rect = range.getBoundingClientRect()
  toolbarX.value = rect.left
  toolbarY.value = rect.top - 50
  showToolbar.value = true

  selectedRange.value = { selectedText, startOffset, endOffset }
}

const saveAnnotation = async () => {
  const annotation = {
    note_id: noteId.value,
    text: selectedRange.value.selectedText,
    start_offset: selectedRange.value.startOffset,
    end_offset: selectedRange.value.endOffset,
    entity_type: selectedEntityType.value,
    confidence: confidence.value,
    manually_reviewed: true
  }

  await api.post('/api/v1/deidentify/annotations', annotation)
  annotations.value.push(annotation)
  showToolbar.value = false
}
```

### 2. Job Dashboard Component (JobDashboard.vue)

**Features**:

          <v-chip :color="statusColor(item.status)">
            {{ item.status }}
          </v-chip>
        </template>

          <v-progress-linear
            :value="(item.processed_notes / item.total_notes) * 100"

          />
        </template>

          <v-btn icon @click.stop="viewJob(item.job_id)">
            <v-icon>mdi-eye</v-icon>
          </v-btn>
          <v-btn icon @click.stop="cancelJob(item.job_id)" v-if="item.status === 'processing'">
            <v-icon>mdi-cancel</v-icon>
          </v-btn>
          <v-btn icon @click.stop="deleteJob(item.job_id)" v-if="item.status !== 'processing'">
            <v-icon>mdi-delete</v-icon>
          </v-btn>
        </template>
      </v-data-table>
    </v-card-text>
  </v-card>
</template>
