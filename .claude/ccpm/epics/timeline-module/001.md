# Task #001: Create Timeline API Endpoint

## Description

Implement the FastAPI endpoint `/api/v1/timeline/patient/{patient_id}` that returns chronological clinical events for a patient from Elasticsearch.

## Technical Specifications

**Endpoint**: `POST /api/v1/timeline/patient/{patient_id}`
**File**: `backend/app/api/v1/endpoints/timeline.py`

**Request Schema**:
```python
class TimelineRequest(BaseModel):
    date_range: DateRangeSchema
    event_types: List[EventType] = ["diagnosis", "procedure", "medication", "lab", "visit"]
    specialty_filter: Optional[str] = None
    page: int = 1
    page_size: int = 1000
```

**Response Schema**:
```python
class TimelineResponse(BaseModel):
    patient_id: str
    patient_name: str
    date_range: DateRangeSchema
    events: List[TimelineEvent]
    total_events: int
    metadata: QueryMetadata
```

## Implementation Requirements

1. **Authentication & Authorization**:
   - Verify user is authenticated (JWT token)
   - Check user has access to this patient (RBAC)
   - Return 403 if unauthorized

2. **Input Validation**:
   - Validate patient_id format
   - Validate date_range (start < end)
   - Validate page and page_size (reasonable limits)

3. **Business Logic**:
   - Query Elasticsearch for patient events
   - Apply filters (date, event types, specialty)
   - Sort events chronologically
   - Paginate results

4. **Audit Logging**:
   - Log every access: `{user_id, patient_id, timestamp, action: "VIEW_TIMELINE"}`
   - HIPAA compliance requirement

5. **Error Handling**:
   - 404 if patient not found
   - 400 for invalid parameters
   - 500 for server errors
   - No PHI in error messages

## Acceptance Criteria

- [x] Endpoint returns correct events for patient_id
- [x] Filtering works (date range, event types, specialty)
- [x] Pagination works correctly
- [x] Response time <500ms for 1,000 events
- [x] Audit log entry created for each request
- [x] All error cases handled
- [x] Unit tests written (>90% coverage)
- [x] Integration tests with Elasticsearch
- [x] OpenAPI docs generated
