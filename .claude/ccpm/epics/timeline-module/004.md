# Task #004: Implement Timeline Filters & Event Detail Modal

## Description

Create the TimelineFilters component for filtering events by date range, event type, and specialty. Implement the EventDetailModal component to show full event details when users click on an event marker.

## Technical Specifications

**Components to Create**:

1. **TimelineFilters.vue**:
   ```vue
   <template>
     <v-card class="timeline-filters">
       <v-date-picker v-model="dateRange" range />
       <v-select v-model="eventTypes" multiple :items="eventTypeOptions" />
       <v-select v-model="specialty" :items="specialtyOptions" />
       <v-btn @click="applyFilters">Apply Filters</v-btn>
     </v-card>
   </template>
   ```

2. **EventDetailModal.vue**:
   ```vue
   <template>
     <v-dialog v-model="isOpen" max-width="600">
       <v-card>
         <v-card-title>{{ event.name }}</v-card-title>
         <v-card-text>
           <EventDetails :event="event" />
           <MetaAnnotations :annotations="event.meta_annotations" />
           <SourceDocument :doc-id="event.source_document_id" />
         </v-card-text>
       </v-card>
     </v-dialog>
   </template>
   ```

**Filter Options**:
- **Date Range**: Date picker with presets (last 30 days, 3 months, 1 year, all)
- **Event Types**: Multi-select (diagnosis, procedure, medication, lab, visit)
- **Specialty**: Single-select (cardiology, oncology, neurology, etc.)

## Implementation Requirements

1. **Filter Logic**:
   - Filters apply in real-time (debounce 300ms)
   - Combine filters with AND logic
   - Show event count for each filter option
   - Reset filters button

2. **Event Detail Modal**:
   - Display full event details (name, date, confidence, codes)
   - Show meta-annotations with visual indicators
   - Link to source document (opens in new tab)
   - Show related events (same concept, different dates)
   - Copy event details to clipboard

3. **Meta-Annotation Indicators**:
   - Negation: Red badge if negated, green if affirmed
   - Temporality: Icon showing time period (current, past, future)
   - Experiencer: Badge showing patient/family/other
   - Certainty: Stars showing certainty level (1-5)

4. **User Experience**:
   - Filter changes update timeline immediately
   - Loading state during filter application
   - Error handling for failed filter requests
   - Filter state persisted in URL query params
