## Test Scenarios

### Scenario 1: Basic Search Flow

```typescript
describe('Search Flow', () => {
  it('performs end-to-end search', async () => {
    // 1. Mount search page
    const wrapper = mount(SearchPage, {
      global: { plugins: [vuetify, router] }
    })

    // 2. User types query
    const searchBar = wrapper.findComponent(SearchBar)
    await searchBar.find('input').setValue('atrial flutter')

    // 3. User presses Enter
    await searchBar.find('input').trigger('keyup.enter')

    // 4. API called with correct params
    expect(mockApi.search).toHaveBeenCalledWith({
      query: 'atrial flutter',
      page: 1,
      page_size: 20,
      sort: 'relevance'
    })

    // 5. Results displayed
    await waitFor(() => {
      expect(wrapper.findAllComponents(SearchResultItem)).toHaveLength(10)
    })

    // 6. Highlights are sanitized
    const firstResult = wrapper.findComponent(SearchResultItem)
    expect(firstResult.html()).toContain('<mark>atrial flutter</mark>')
    expect(firstResult.html()).not.toContain('<script>')
  })
})
```
