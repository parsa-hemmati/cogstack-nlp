**Example**:
```markdown
# Search Security

## XSS Prevention

The search module prevents XSS attacks by sanitizing all HTML
before rendering with v-html.

### Sanitization Strategy
- **Library**: DOMPurify
- **Allowed Tags**: `<mark>` only
- **Allowed Attributes**: None
- **Policy**: Strip all scripts, event handlers, and dangerous tags

### Implementation
\`\`\`typescript
import { sanitizeHtml } from '@/utils/sanitize'

const safeHtml = sanitizeHtml(result.highlights.title[0])
\`\`\`

### Testing
All search results are tested with malicious payloads:
- `<script>alert('XSS')</script>`
- `<img src=x onerror="alert(1)">`
- `<iframe src="evil.com"></iframe>`

See: tests/unit/utils/sanitize.spec.ts
```

### 6. Troubleshooting Guide (troubleshooting.md)

**Common Issues**:

2. Highlights not showing
3. XSS warnings in console
4. Slow search performance
5. Pagination not working

**Format**:
```markdown
## Issue: Search results not displaying

**Symptoms**:
- Search completes but no results shown
- No error messages in console

**Possible Causes**:
1. API endpoint not reachable
2. Results array empty
3. Component not reactive

**Solutions**:
1. Check API endpoint: `POST /api/v1/search`
2. Verify API response structure
3. Check console for network errors
4. Ensure `results` is a Ref

**Example Fix**:
\`\`\`typescript
// ❌ Wrong
const results = []

// ✅ Correct
const results = ref<SearchResult[]>([])
\`\`\`
```
