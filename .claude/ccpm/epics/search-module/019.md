# Task #019: Create useSearch Composable

## Description

Create a Vue 3 composable that encapsulates search functionality including API calls, state management, and result handling.

## API Integration

**Endpoint**: `POST /api/v1/search`

**Request**:
```typescript
interface SearchRequest {
  query: string
  filters?: {
    negation?: string
    temporality?: string
    experiencer?: string
  }
  page: number
  page_size: number
  sort: 'relevance' | 'date_desc' | 'date_asc' | 'title_asc' | 'title_desc'
}
```

**Response**:
```typescript
interface SearchResponse {
  results: SearchResult[]
  total: number
  page: number
  page_size: number
  query: string
}

interface SearchResult {
  id: string
  title: string
  content: string
  document_type: string
  author: string
  date: string
  score: number
  highlights?: {
    title?: string[]
    content?: string[]
  }
}
```

## Implementation Requirements

1. **Debounced Search**: Use `watchDebounced` from VueUse to debounce search input (300ms)

2. **Error Handling**: Catch and display API errors gracefully

3. **Loading States**: Set `isLoading` appropriately during API calls

4. **Cache**: Cache recent searches (last 10) to avoid redundant API calls

5. **TypeScript**: Full type safety with proper interfaces
