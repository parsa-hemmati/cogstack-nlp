# Task #020: Create SearchBar Component

## Description

Create a Vue 3 component for the search input bar that integrates with the useSearch composable and provides a clean UI for searching clinical documents.

## Technical Specifications

**File**: `frontend/src/components/search/SearchBar.vue`

**Component Structure**:
```vue
<template>
  <v-card>
    <v-card-text>
      <v-text-field
        v-model="searchQuery"
        label="Search documents"
        prepend-inner-icon="mdi-magnify"
        append-icon="mdi-close"
        :loading="isLoading"
        clearable
        @keyup.enter="handleSearch"
        @click:append="clearSearch"
      />
    </v-card-text>
  </v-card>
</template>

<script setup lang="ts">
import { ref, watch } from 'vue'
import { useSearch } from '@/composables/useSearch'

const { search, clearSearch, isLoading } = useSearch()
const searchQuery = ref('')

watch(searchQuery, (newQuery) => {
  if (newQuery) {
    search(newQuery)
  }
})
</script>
```

## UI Requirements

1. **Input Field**:
   - Full-width text input
   - Placeholder: "Search clinical documents..."
   - Magnifying glass icon (prepend)
   - Clear button (X icon, append)

2. **Loading State**:
   - Show loading spinner in input when searching
   - Disable input during search
   - Loading indicator from useSearch composable

3. **Keyboard Support**:
   - Enter key triggers search
   - Escape key clears search
   - Tab navigation works correctly

4. **Responsive Design**:
   - Mobile: Full width, larger touch targets
   - Tablet: Full width with margins
   - Desktop: Max-width 800px, centered
