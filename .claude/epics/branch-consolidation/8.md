### Test Infrastructure Consolidation

**pytest Configuration** (`pytest.ini`, `conftest.py`):
```ini
[pytest]
testpaths = tests
python_files = test_*.py
python_classes = Test*
python_functions = test_*
addopts =
    --cov=app
    --cov-report=html
    --cov-report=term-missing
    --cov-fail-under=85
    --maxfail=5
    --tb=short
markers =
    unit: Unit tests
    integration: Integration tests
    e2e: End-to-end tests
    performance: Performance tests
    slow: Slow tests (>1s)
```

**Vitest Configuration** (`vitest.config.ts`):
```typescript
export default defineConfig({
  test: {
    globals: true,
    environment: 'jsdom',
    coverage: {

      threshold: {
        global: {
          statements: 85,
          branches: 80,
          functions: 85,
          lines: 85
        }
      }
    },
    include: ['frontend/tests/**/*.test.ts'],
    exclude: ['node_modules', 'dist']
  }
})
```

### Consolidation Strategy

**Deduplication**:
1. Identify duplicate tests (same functionality, different branches)
2. Keep most comprehensive version
3. Merge complementary assertions
4. Remove redundant tests

**Conflict Resolution**:
1. Different expected behavior → Run both, document why
2. Outdated test → Update to match consolidated code
3. Incompatible mocks → Standardize mock data

**Test Fixtures**:
1. Consolidate fixtures into `tests/fixtures/`
2. Standardize patient test data
3. Standardize MedCAT response mocks
4. Standardize FHIR resource examples

### Validation Approach

**Phase 1: Unit Tests** (1 hour)
```bash
# Backend
pytest tests/unit -v --cov=app/services --cov=app/models

# Frontend
npm run test:unit -- --coverage
```

**Phase 2: Integration Tests** (1 hour)
```bash
# Backend (requires services running)
docker-compose up -d postgres elasticsearch medcat
pytest tests/integration -v

# Frontend
npm run test:integration
```

**Phase 3: E2E Tests** (30 min)
```bash
# Full stack (requires all services)
docker-compose up -d
pytest tests/e2e -v
npm run test:e2e
```

**Phase 4: Performance Tests** (30 min)
```bash
# Benchmarks
pytest tests/performance --benchmark-only
npm run test:performance
```

**Flaky Test Protocol**:
1. Identify flaky tests (inconsistent pass/fail)
2. Root cause: Timing issues? Race conditions? External dependencies?
3. Fix or quarantine (mark with `@pytest.mark.flaky` or `test.todo()`)
4. Track in CONTEXT.md under "Known Issues"

**CI/CD Integration**:

- Block merge if tests fail
