# Task: Environment Setup

## Description
Configure the project management system, GitHub authentication, and git worktrees to enable efficient parallel consolidation of 6 branches. This task establishes the foundation for all subsequent consolidation work by setting up the tools and environment needed for safe, parallel branch analysis and merging.

## Acceptance Criteria
- [ ] GitHub CLI authenticated and tested
- [ ] Git worktrees created for each branch
- [ ] PM system (Claude Code Tasks) configured
- [ ] Branch analysis checklist created
- [ ] Merge conflict resolution strategy documented
- [ ] Testing environment validated
- [ ] Documentation structure ready

## Technical Details
- **Branches to analyze**: ccpm-consolidated (current), medcat-v2.0-integration, medcat-v2.3-integration, trainer-ui-integration, demo-app-integration, query-parser-integration, elasticsearch-integration
- **Key tools**:
  - GitHub CLI (`gh`) for PR management
  - Git worktrees for parallel branch work
  - Claude Code TodoWrite for task tracking
- **Setup strategy**:
  - Create worktrees in `.worktrees/` directory
  - Configure git to ignore worktree directories
  - Document branch mapping and commit ranges

## Dependencies
- [ ] Task dependencies: None (foundation task)
- [ ] Tools: Git (installed), GitHub CLI (to be configured)
- [ ] Permissions: GitHub repo write access

## Effort Estimate
- Size: S
- Hours: 2
- Parallel: false

## Subtasks
1. **GitHub Authentication** (30 min)
   - Install/update GitHub CLI if needed
   - Authenticate with GitHub: `gh auth login`
   - Verify access: `gh repo view`
   - Test PR creation capabilities

2. **Git Worktrees Setup** (45 min)
   - Create `.worktrees/` directory
   - Add to `.gitignore`
   - Create worktree for each branch:
     ```bash
     git worktree add .worktrees/medcat-v2.0 medcat-v2.0-integration
     git worktree add .worktrees/medcat-v2.3 medcat-v2.3-integration
     git worktree add .worktrees/trainer-ui trainer-ui-integration
     git worktree add .worktrees/demo-app demo-app-integration
     git worktree add .worktrees/query-parser query-parser-integration
     git worktree add .worktrees/elasticsearch elasticsearch-integration
     ```
   - Verify all worktrees: `git worktree list`

3. **Branch Analysis Setup** (30 min)
   - Document commit ranges for each branch
   - Create comparison checklist template
   - Set up diff analysis commands
   - Document merge strategy (3-way merge vs cherry-pick)

4. **Testing Environment** (15 min)
   - Verify Docker setup
   - Check test suite runs: `pytest`
   - Validate CI/CD pipeline access
   - Ensure all dev dependencies installed

## Definition of Done
- [ ] GitHub CLI authenticated and working
- [ ] All 6 worktrees created and accessible
- [ ] `.worktrees/` added to `.gitignore`
- [ ] Branch analysis documentation created
- [ ] Test environment validated
- [ ] Team can access and use all tools
- [ ] Documentation updated in CONTEXT.md

## Notes
- This task MUST be completed before any parallel consolidation work begins
- Worktrees enable safe parallel analysis without branch switching
- GitHub CLI enables PR automation for consolidated features
- Proper setup prevents merge conflicts and lost work
